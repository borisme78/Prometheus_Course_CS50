# Основи програмування CS50

Репозиторій із навчальними завданнями, прикладами з лекцій і практичними роботами курсу **«Основи програмування CS50»**. Матеріали охоплюють програмування мовами C і Python, роботу з файлами та пам’яттю, структури даних, основи веброзробки й бази даних.

## Структура репозиторію

| Папка | Зміст |
| --- | --- |

| [week1](week1/) | Основи C: піраміда Mario, розрахунок решти Cash, перевірка номерів карток Credit та інші вправи. |
| [week2](week2/) | Рядки, аргументи командного рядка, шифри Цезаря й Віженера та завдання Crack. |
| [week3](week3/) | Робота з двійковими файлами: обробка BMP у Whodunit, зміна розміру зображень у Resize та відновлення JPEG у Recover. |

Нумерація папок відповідає матеріалам у цьому репозиторії. Завдання й лекційні приклади зберігаються окремими програмами, кожна з яких запускається зі своєї папки.

## Технології

- **C** — базові алгоритми, рядки, пам’ять і файли.
- **Python 3** — консольні програми та серверна логіка.
- **HTML, CSS, JavaScript** — вебсторінки та взаємодія з користувачем.
- **Flask і Jinja** — маршрути, форми та шаблони.
- **SQL і SQLite** — збереження й обробка даних.
- **Бібліотека CS50** — допоміжні функції та доступ до баз даних у частині завдань.

## Запуск прикладів

### Програми мовою C

Потрібен компілятор Clang або GCC. Наприклад, із кореня репозиторію:

```sh
cd week1
clang mario_height.c -o mario_height
./mario_height
```

Для програм, які підключають `cs50.h`, потрібно окремо встановити бібліотеку CS50 для C і додати `-lcs50` під час компіляції.

У завданні Speller є власний `Makefile`:

```sh
cd week4
make
./speller dictionaries/large texts/cat.txt
```

### Програми мовою Python

Створіть віртуальне середовище в корені репозиторію та встановіть бібліотеку CS50:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install cs50
python week6/hello.py
```

Окремі приклади мають додаткові залежності. Якщо в папці є `requirements.txt`, установлюйте їх командою `python -m pip install -r requirements.txt` із цієї папки.

### Вебзастосунки Flask

Приклад запуску опитування Survey з активованим віртуальним середовищем, із кореня репозиторію:

```sh
python -m pip install Flask
cd week7/survey
python -m flask --app application run
```

Відкрийте в браузері адресу, яку Flask виведе в терміналі. Зазвичай це `http://127.0.0.1:5000`.

Застосунок Finance використовує SQLite та API Finnhub для отримання котирувань. Для нього потрібні залежності з `week8/finance/requirements.txt`, додатковий пакет `finnhub-python`, база `finance.db` з відповідними таблицями та налаштований доступ до API в `helpers.py`. Старі лекційні приклади можуть потребувати адаптації до встановлених версій бібліотек.
